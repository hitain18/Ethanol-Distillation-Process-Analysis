# Ethanol Distillation Process Analysis & Predictive Monitoring

A Chemical Engineering and Data Science project combining DWSIM process
simulation with Python-based process analysis and predictive monitoring.

## Overview

This project investigates an ethanol-water distillation process using
DWSIM simulation data and Python-based analysis.

The workflow combines:

- Process simulation
- Distillation analysis
- Data preprocessing
- Statistical analysis
- Machine learning
- Predictive process monitoring
- Engineering visualization

The objective is to demonstrate how process simulation data can be
converted into actionable engineering insights using computational tools.
